# ローカライズのトーンガイドとコンテンツ設計

提案文（`SuggestionTemplates` / `weatherContextFormat`）を各言語に展開するときの指針。
**機械翻訳をそのまま入れないこと。** ここに書いた方針に沿って書き起こす。

対象言語: ja（原文） / en / ko / es / fr

---

## 1. 何を守るか

このアプリの提案文は、情報を伝えるだけの文ではない。「すきま時間に小さな偶然を見つける」という体験そのものを作っている。翻訳で失われやすいのは次の3つ。

| 要素 | 日本語での現れ方 | 各言語で守ること |
|---|---|---|
| **押しつけない誘い** | 「〜しませんか」「〜はいかがですか」 | 命令形を避ける。提案であって指示ではない |
| **軽さ・余白** | 「ほっとひと息」「気分転換に」 | 大げさな形容を足さない。短く、息を抜いた調子 |
| **二人称の距離感** | 主語を省略し、押しが弱い | 各言語の**丁寧だが親しい**レジスタを選ぶ |

### 二人称の指定

| 言語 | 使う形 | 理由 |
|---|---|---|
| en | you（カジュアル寄り、命令形は避ける） | "Why not..." "Maybe it's a good day to..." |
| ko | **해요体**（합니다体は硬すぎる） | 丁寧だが親しい。아파트の広告文のような距離感 |
| es | **tú**（usted は他人行儀） | 生活アプリの標準。命令形は避け "puedes" などを使う |
| fr | **tu**（vous は距離が出すぎる） | 同上。"tu peux" "et si tu..." |

**ko で 합니다体、es/fr で usted/vous を使わないこと。** 硬くなって体験が変わる。

### 避けること

- 感嘆符の多用（日本語原文にある「！」も、各言語で自然でなければ落とす）
- 「〜すべき」「〜しなければ」に相当する義務の言い回し
- マーケティング的な誇張（"amazing" "perfect" の乱用）
- 絵文字の追加（原文にあるもの以外は足さない）

## 2. 天気文脈のプレースホルダ

`weatherContextFormat` は `%@` に天気語（「晴れ」「曇り」等）が入る。

```
ja: "%@。テラス席も気持ちよさそうです。"
```

**日本語の語順に引きずられないこと。** `%@` を文頭に置く必要はない。

```
en: "It's %@ — the terrace looks lovely."
fr: "Il fait %@, la terrasse a l'air agréable."
```

`%@` を**必ず1つ含めること**。落とすと天気の文脈が消える（テストで検出される）。

## 3. カテゴリのコンテンツ設計

10カテゴリのうち、**そのまま訳すと成立しないもの**がある。「その国で同じ気持ちになれる場所は何か」から考える。

| カテゴリ | ja の想定 | 各言語での置き換え方針 |
|---|---|---|
| cafe | カフェ | そのまま。どの国にもある |
| walk | 近所の散歩・公園 | そのまま |
| reading | 図書館・書店・ブックカフェ | そのまま。es/fr の「librería/librairie」は書店（図書館ではない） |
| music | レコード店・ライブハウス | そのまま。ただし ko はライブ文化の呼称が違う（#45 参照） |
| art | 美術館・ギャラリー | そのまま |
| fitness | ジム・ヨガ | そのまま |
| shopping | 雑貨・ウィンドウショッピング | そのまま |
| gourmet | 食べ歩き・新しい店 | そのまま。ただし「食べ歩き」は歩きながら食べる行為で、欧州では行儀が悪いとされる場面がある。「新しい店を試す」寄りに書く |
| movie | 映画館・ミニシアター | そのまま |
| **meditation** | **お寺・神社・庭園で心を静める** | **要設計。下記** |

### meditation の設計

日本の「寺社で心を静める」に**直接対応する場所は多くの国に無い**。「静かに心を落ち着けられる場所」という意図を残して置き換える。

| 言語 | 置き換え先 | 提案文の方向性 |
|---|---|---|
| ja | お寺・神社・庭園 | 「日常から離れて、穏やかな時間を」 |
| en | garden, quiet park, meditation space | 宗教色を出さず「静けさ」に寄せる |
| ko | 절（寺）・고궁（古宮）・정원 | 寺と古宮は韓国でも「静かに過ごす場所」として成立する |
| es | jardín, claustro, iglesia | 教会や修道院の中庭が文化的な対応物 |
| fr | jardin, église, parc | 同上 |

検索キーワード側の対応は #45 で実装済み。**文言と検索キーワードで方針を揃えること。**

### gourmet の注意

「食べ歩き」は日本では肯定的だが、路上での飲食が好まれない地域がある。en/es/fr では「新しい店を開拓する」「地元の味を試す」方向に書き換える。

## 4. 構造上の制約

**テンプレートの「枠」は全言語で共通。** カテゴリごとのテンプレート数（現在は各2〜3件、計29件）と `minDuration` は言語で変えられない。

変えられるのは**各枠に入る文言**だけ。ただし文言は完全に別の内容にしてよいので、実用上は「その言語で成立する提案」を書ける。

言語ごとにテンプレートの**数**を変えたくなった場合は、String Catalog では表現できないため構造から見直しが必要になる。現時点ではその必要は無いと判断している。

## 5. 作業の進め方

1. **en を先に完成させる。** 他3言語のリファレンスになる
2. en が固まってから ko / es / fr に展開する
3. 各言語、最低1人はその言語を実用レベルで使える人が通す
4. 未翻訳キーが残った状態でリリースしない（String Catalog は既定で ja にフォールバックするため、英語圏に日本語が出る事故になる）

翻訳の投入自体は #36 で行う。
